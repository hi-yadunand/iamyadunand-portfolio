# Portfolio statistics backgrounds

Generated with the built-in image generation tool. Optimized local WebP copies are used by the four statistics cards in `index.html`. The existing hover reveal, dark overlays, statistics and counters are retained.

## Final assets and prompts

### years-building.webp

Use case: stylized-concept. Asset type: portrait photographic-quality 3D background for a software engineer and designer's portfolio statistics card. Create ONE full-bleed 4:5 portrait image, not a website mockup. Art direction: elegant editorial technology still life, physically plausible tactile objects, near-black charcoal #111111, graphite, brushed silver, restrained vermilion orange #d63f1c accents. Precise geometry, soft rim lighting, realistic shadows, quiet premium mood, no neon rainbow, no cyberpunk. Composition: main subject centered in middle 55% of image, ample dark negative space at top left and along bottom so white HTML statistics can overlay legibly. Do not render any typography, numbers, logos, letters, watermarks or card borders. Subject: a beautifully crafted silver mechanical keyboard on a charcoal developer desk in a dramatic close overhead three-quarter view, a few vermilion keys and one slim glowing orange trace forming a subtle path behind it. Suggest patient craft, years of coding and iteration. Crop aesthetically, no monitor, no hands.
