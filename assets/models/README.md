# Drone models

`drone.glb` is the active black-and-white drone, restored to match the original
website model. The current scene supplies its lighting, framing, pointer movement,
animated propellers, reduced-motion handling and resource disposal.

- **S9 Mini Drone** by **Vaptor-Studio**
- Source: https://sketchfab.com/models/cf3ed83c1b87486d90435f54c074e16e
- License: https://creativecommons.org/licenses/by/4.0/

`camera-free-drone.js` is an unused alternative retained for recovery. It is not
imported by the active scene.
